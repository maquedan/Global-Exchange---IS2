Horarios operativos
===================

RF037 (GEG9-79) permite que el administrador configure los rangos de atención
en los que se pueden iniciar o confirmar operaciones. Se pueden definir varios
rangos para un mismo día; fuera de ellos, compra y venta quedan bloqueadas,
mientras que la consulta de tasas y la simulación siguen disponibles.

La comprobación usa la zona horaria local del sistema y mantiene la operación
abierta mientras todavía no existe ninguna configuración, para permitir la
puesta en marcha inicial.
